## Arabic (ar) — Locale-Specific Rules

- RTL language. Placeholders and brand names (POS, WooCommerce) stay LTR within RTL text.
- Use Modern Standard Arabic (فصحى) for UI text.
- Required terminology: إيصال (Receipt), نقطة البيع (Checkout), الكاشير (Cashier), بوابة الدفع (Payment Gateway), قالب (Template).
- Use "قالب" consistently for "template" — not "نموذج" (which means model/form).
- Arabic grammar with placeholders: use singular noun form after {count}/{days}/{hours} placeholders — the numeral handles plurality.
