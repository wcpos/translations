## Spanish (es_ES) — Locale-Specific Rules

- Use formal "usted" throughout — this is business software for store owners and staff.
- Do NOT mix tú and usted within the same application. Every string must use usted conjugation.
- Required terminology: Recibo (Receipt, NOT Factura which means invoice), Caja (Checkout), Cajero (Cashier), Pasarela de pago (Gateway), Plantilla (Template), Reembolso (Refund).
- "Factura" means formal invoice — never use it for POS receipts.
- Decimal separator is comma: 0,25 not 0.25.
