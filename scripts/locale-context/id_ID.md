## Indonesian (id_ID) — Locale-Specific Rules

- Use standard Indonesian (Bahasa Indonesia), not Malay. "Pratinjau" not "Pratonton".
- Required terminology: Struk (Receipt — the common Indonesian word from Dutch "strook"), Pembayaran (Checkout), Kasir (Cashier), Gateway pembayaran (Payment gateway, as in WooCommerce), Templat (Template, as in WooCommerce).
- Use "Struk" consistently for all receipt contexts — NOT "Tanda Terima" (formal acknowledgment) or "Kwitansi" (formal invoice receipt).
- "Checkout" as a process = "Pembayaran", NOT "Kasir" (which means the cashier person).
- Avoid unnecessary reduplication in UI strings — "pesanan" not "pesanan-pesanan", "templat" not "templat-templat".
- Natural word order: "produk POS saja" not "produk hanya POS".
