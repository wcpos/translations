## Japanese (ja) — Locale-Specific Rules

- Use the polite です/ます style in sentences and messages, as ja already ships; buttons, tabs and column headers are short nouns (再試行, 保存).
- Required terminology (from glossary): レシート (Receipt), レジ (Checkout), レジ係 (Cashier), ドロワー (cash drawer; never 現金引き出し, which reads as a cash withdrawal).
- A label that names a person (Refunded by, Cashier) is a noun such as 担当者, never a particle fragment like による.
- Short forms (packet `short_forms`): 数量 (Qty), 再試行 (Retry), エコ (Eco); keep ID and FAQ in Latin letters.
- Decimal separator is a period: 0.25.
- Use 「 and 」 for quotation marks, not straight quotes.
