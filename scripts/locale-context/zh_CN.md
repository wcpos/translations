## Chinese, Simplified (zh_CN) — Locale-Specific Rules

- Address the user as 您, as zh_CN already ships; do not mix in 你.
- Required terminology (from glossary): 收据 (Receipt), 收银台 (Checkout), 收银员 (Cashier), 关账 (Closure), 磁贴 (UI tile; never 瓷砖, which is a ceramic tile).
- A document is 文档, not 文件 (file).
- A label that names a person (Refunded by, Cashier on an order) is 操作人, never a fragment like 由.
- Short forms (packet `short_forms`): 数量 (Qty), 重试 (Retry); keep ID in Latin letters.
- Decimal separator is a period: 0.25.
- Use “ and ” for quotation marks, not straight quotes.
